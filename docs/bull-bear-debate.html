Bull vs bear AI debate: Claude agents argue NVIDIA, Tesla and Apple from cited 10-K evidence

A Bull agent and a Bear agent may only use numbered facts from each company's latest annual report and market data, and must cite an ID after every claim. Each rebuts the other, a Judge scores evidence quality, and code checks every citation against the evidence pack.

How one debate runs

1 Evidence39 numbered facts: [R] risk factors, [M] management discussion, [F] SEC financials, [P] market data.
2 BullBuy case in up to 250 words, an evidence ID after every claim.
3 BearAvoid or sell case under the same rule.
4 RebuttalEach side answers the other's two strongest points.
5 Code checkInvented IDs and uncited paragraphs flagged; each invented ID costs 1 point.
6 JudgeJSON verdict: scores, strongest points, unsupported claims, what would change it.

The agents' instructions

What is real here

The evidence packs and the referee signals come from SEC filings and market data and are shown as computed. The prompts are the exact instructions each agent receives.

The live debate needs an Anthropic API key, which was not available when this was built, so no Claude-written arguments or verdicts are shown. Running python debate.py with a key writes the full debate, the Judge's JSON and the citation check for each stock. Seven tests run the whole five-call debate with a scripted stand-in.
