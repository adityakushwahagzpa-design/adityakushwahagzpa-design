Customer 360: one trusted record per customer, and the next best action for each

Records from core banking, CRM and the card system are matched into golden customers, joined into a 40-feature profile, and scored for churn risk, product propensity and 5-year value. A next-best-action engine respects credit and KYC guardrails, and a Claude assistant writes relationship-manager briefs from the same tools.

Look up a customer

The brief is the rule-based version, built from the same tool output Claude receives (get_customer_360). With an Anthropic API key, python rm_assistant.py --brief <id> has Claude write it. All customers are synthetic.

Matching records across systems

Precision, recall and F1 on held-out people. The model compares names (Jaro-Winkler, token sort), phone, email, date of birth and city; core banking is the system of record.

Churn model on the real future

Trained on Sep 2025, tested on who actually left in Apr–Sep 2026.
