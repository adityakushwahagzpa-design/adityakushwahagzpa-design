How to read the results

All data is synthetic, built so the true answer is known and every model can be checked, except the debate, which uses real SEC filings and market data. Each page shows measured accuracy next to the method.

The Claude agents were built and tested with scripted stand-ins, but the live AI answers (debate verdicts, written briefs and memos, text-to-SQL accuracy) need an Anthropic API key and are not shown. Every page says exactly what is computed and what needs a key.
